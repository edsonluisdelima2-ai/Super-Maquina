# Componentes locais de vídeo

- FFmpeg 6.1.1, build Windows essentials da Gyan.dev, projeto FFmpeg: https://ffmpeg.org/
- Faster-Whisper 1.2.1 (MIT): https://github.com/SYSTRAN/faster-whisper
- CTranslate2 e PyAV, instalados como dependências do Faster-Whisper.
- Modelo Whisper `small`, armazenado em `runtime/models/small` para uso local.

As licenças e metadados dos pacotes Python permanecem em `runtime/python-standalone/Lib/site-packages/*dist-info`.
